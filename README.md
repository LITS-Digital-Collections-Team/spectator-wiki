# Hamilton Gazetteer (spectator-wiki)
Wiki covering topics in Hamilton College history, generated by scraping text from Spectator back-issues, course catalogs, and college archival publications, then using the results as source data for "Mnemotron-R" (https://github.com/pwallace/mnemotron-wiki-r)

See https://lits-digital-collections-team.github.io/spectator-wiki/index.html for the live demo.
